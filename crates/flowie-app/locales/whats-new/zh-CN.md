# 更新说明

`CHANGELOG.md` 各版本说明的简体中文版，供「新功能」页面使用。每个版本一节，标题与 `CHANGELOG.md` 相同；
缺少某个版本时，该版本显示英文原文。

## [1.0.0-rc.3] - 2026-11-22

### 新增

- 文字颜色快捷键：⌘⌃1 到 ⌘⌃7 依次为红、橙、黄、绿、蓝、紫、灰，⌘⌃0 去掉颜色，⌘⌃C 按此顺序切换到下一种颜色。
  有选中文字时给文字上色；没有选中时给整个条目上色（并选中它，便于看到颜色、继续按 ⌘⌃C 切换）；也可以给所有选中的条目上色。
  对已有该颜色的文字再按一次会去掉颜色。这些命令也在「格式」菜单中，可在设置里修改。
- Flowie 会按上次离开时的大小和位置、在同一块显示器上重新打开窗口，上次全屏则仍为全屏。那块显示器已断开时窗口居中打开；
  窗口会超出显示器时会被移回并缩小到合适大小。
- Windows 10 和 11（64 位）：每个 GitHub 发布都附带 `Flowie-<version>-windows-x64.zip`。窗口有自己的菜单栏，macOS 上用 ⌘ 的快捷键改用 Ctrl。
  由于很多键盘上 Ctrl+Alt 就是 AltGr，默认快捷键都不用它：块类型为 Ctrl+Shift+0 到 Ctrl+Shift+8，后退和前进为 Alt+← 和 Alt+→，
  镜像为 Alt+M，文字颜色为 Alt+0 到 Alt+7 和 Alt+C。大纲保存在 `%LOCALAPPDATA%\Flowie`。Linux 可从源码构建，快捷键相同，并有 CI 检查。
- Flowie 已经打开时再次打开它，会把已打开的窗口带到前面，而不是再打开一份同一个大纲。`flowie mcp` 为智能体启动 Flowie 时，窗口不再抢占焦点。

### 变更

- 快捷键提示、提示条和教程会按你在设置中设定的快捷键显示，并使用系统的写法（macOS 上为 ⇧⌘P，其他系统为 Ctrl+Shift+P）。
- 当 Flowie 使用的不是默认数据库时，「设置 → 智能体」中的 `claude mcp add` 命令和 MCP 客户端配置会带上 `FLOWIE_DB`。
- 用鼠标滚轮滚动大纲更平滑了：每格滚动都会平滑滑动，和触控板一样，不再跳跃。
- 浅色主题中，橙色和黄色文字与红色以及彼此之间更容易区分。
- GitHub 上的候选版本不再标记为预发布，最新版本（包括候选版本）会标记为最新发布。
- Homebrew cask `wesleyel/tap/flowie` 现在也提供候选版本，`flowie@beta` 已移除：`brew upgrade` 会把已安装的 `flowie@beta` 换成 `flowie`。
- 在待办或编号条目上按 Enter，下一行会是同一类型（新待办为未勾选），新的第一个子条目沿用下方子条目的类型。
  在空的待办或编号条目上按 Enter 会把它变回普通条目，结束列表。

### 修复

- 重新打开一个条目时会回到你之前滚动到的位置，而不是它的顶部，退出并重新启动 Flowie 后也是如此。

## [1.0.0-rc.2] - 2026-11-19

### 新增

- 每个 GitHub 发布都附带开源版 `Flowie-<version>-macos.zip`：适用于 macOS 13 及更高版本的通用构建，临时签名，未经公证。
- Homebrew cask：`brew install --cask wesleyel/tap/flowie`，随每次发布更新。
- 右键点击条目的圆点会打开条目菜单：打开、展开或折叠下方全部内容、完成、加星、更改块类型、复制条目或其链接、创建副本、移动、
  镜像到另一个条目、导出和删除，还会显示创建和编辑时间以及哪些条目链接到它。在选区内使用时作用于每个选中的条目。
- 大纲、废纸篓、设置页面、弹出框、命令面板、`/` 菜单和右键菜单都有 macOS 悬浮样式的滚动条；比窗口高的菜单可以滚动。
- 文字的右键菜单现在以剪切、复制和粘贴开头，没有选中内容时只显示粘贴。

### 变更

- 更像 Mac 的外观：macOS 系统颜色和强调色，高亮项以强调色填充的菜单，更圆润的菜单、弹出框和面板，以及更柔和的阴影，
  Mac 风格的分段控件、按钮、复选框、键帽和搜索框，提示条与窗口配色一致而不是反色。快速打开、`/` 菜单和设置中的选中行以强调色填充。
- Flowie 现在基于 Zed 的 GPUI 的当前快照（通过 gpui-kit），而不是 2025 年的版本。设置中输入的无法识别的快捷键现在会被跳过，而不会让应用停止运行。

### 修复

- 编辑条目时，Mac 的 Emacs 风格编辑键现在可用：⌃A / ⌃E 到行首或行尾，⌃B / ⌃F / ⌃P / ⌃N 移动，⌃H / ⌃D 删除，⌃K 删除到行尾，
  ⌃Y 放回删掉的文字。它们和其他快捷键一样可以在设置中修改。
- 用鼠标选择文字时会吸附到最近的字符边界，和其他 Mac 应用一样：拖过字符中点就选中该字符，而不必拖过整个字符。

## [1.0.0-rc.1] - 2026-11-18

Flowie 1.0.0 的第一个候选版本，以 GPL-3.0-or-later 授权的自由软件。1.0.0 正式版将在 [Mac App Store](https://apps.apple.com/app/id6835913837) 和这里发布。

### 新增

- **大纲**：每个条目都是一个可以放大进入和退出的页面，带流畅动画；可以缩进、折叠、移动和拖动条目，也可以对多个选中的条目操作。
- **格式**：标题、待办、编号列表、引用、代码块和纯文本，可用键盘或 `/` 菜单设置；粗体、斜体、删除线、高亮、七种颜色和链接，
  只在正在编辑的条目上显示标记。任何条目下都可以写备注；一切操作都可撤销。
- **数学公式**：行内 `$…$` 和独立 `$$…$$` 的 LaTeX，原生渲染并实时预览。
- **链接和镜像**：用 `[[` 创建链接并显示反向链接；镜像可以把一个条目显示在多个地方。
- **标签、提及和日期**：带补全的 `#标签` 和 `@提及`，以及可点击的日期。
- **日记**：每天一页，并有日历。
- **快速打开和搜索**：⌘P 可跳转到任意条目、星标页面或保存的搜索，也可以新建页面。搜索可按短语、标签、人物、待办状态、标题、备注、日期和最近修改筛选。
- **本地存储**：Mac 上的一个 SQLite 数据库；无需账户，没有云端，没有跟踪。
- **导入和导出**：导入 OPML、Markdown 和文本（包括 Workflowy 导出的文件），导出 Markdown、OPML 或文本。删除的条目在废纸篓保留 30 天。
- **键盘**：每个操作都有可自定义的快捷键，包括鼠标侧键，并内置教程。
- **外观和语言**：浅色和深色主题、强调色，以及 English 和简体中文。
- **AI 助手**：内置 MCP 服务器让 Claude 等助手读取大纲，在「设置 → 智能体」允许后还可以编辑。
- **帮助菜单**：发送反馈、教程、隐私政策和使用条款。

### 安全

- 内置 SQLite 3.54.1（通过 rusqlite 0.43），修复 CVE-2026-119375。
