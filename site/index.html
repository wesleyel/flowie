Getting started

Flowie opens with a tutorial page that walks through every feature. To get it back at any time, choose Help → Flowie Tutorial.

Common questions

Where are my notes stored?
Only on your Mac, inside Flowie's app container. Flowie has no account and no cloud sync, and it makes no network requests of its own.

How do I move my notes from Workflowy or another outliner?
Export from the other app as OPML or Markdown, then use File → Import… (⌘⇧I).

How do I back up or export?
Use File → Export to save Markdown, OPML or plain text. Time Machine also backs up Flowie's data.

I deleted something by mistake.
Press ⌘Z, or open File → Trash: deleted bullets stay there for 30 days.

Can I change the shortcuts?
Yes. Open Settings (⌘,) and click any shortcut to record a new one; mouse side buttons work too.

How do AI assistants connect?
Turn it on in Settings → Agent, then register Flowie's MCP server, for example: claude mcp add flowie -- /Applications/Flowie.app/Contents/MacOS/Flowie mcp

常见问题

笔记保存在哪里？
只保存在你的 Mac 上、Flowie 的应用容器内。Flowie 没有账号和云同步，自身不发起任何网络请求。

如何从 Workflowy 等大纲工具迁移？
在原应用中导出 OPML 或 Markdown，然后在 Flowie 中选择「文件 → 导入…」（⌘⇧I）。

如何备份或导出？
通过「文件 → 导出」保存为 Markdown、OPML 或纯文本。时间机器也会备份 Flowie 的数据。

误删了内容怎么办？
按 ⌘Z，或打开「文件 → 废纸篓」：删除的条目会保留 30 天。

可以修改快捷键吗？
可以。打开设置（⌘,），点击任意快捷键即可重新录制，也支持鼠标侧键。

如何连接 AI 助手？
在「设置 → Agent」中开启，然后注册 Flowie 的 MCP 服务器，例如：claude mcp add flowie -- /Applications/Flowie.app/Contents/MacOS/Flowie mcp
