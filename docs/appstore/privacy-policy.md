# Flowie Privacy Policy

Last updated: 2026-11-17

Flowie does not collect, store on any server, share or sell any personal
information.

- **Your notes stay on your Mac.** Everything you write is saved in a database
  inside Flowie's app container on your Mac. Flowie has no accounts, no cloud
  sync, no analytics, no advertising and no crash reporting, and it makes no
  network requests of its own.
- **Files you choose.** When you import or export, Flowie reads or writes only
  the file you pick in the Open or Save dialog.
- **Links.** Clicking a web link opens it in your default browser; what happens
  there is governed by that website's policy.
- **AI agents (optional).** If you connect an AI assistant (for example Claude)
  through Flowie's MCP server, the assistant can read — and, if you allow it in
  Settings → Agent, change — your outline. That access goes through a local
  connection on your Mac only. What the assistant does with the content it
  reads is governed by that assistant's provider. You can turn agent access off
  at any time.
- **Children.** Flowie collects no data from anyone, including children.

If this policy changes, the new version will be posted at this address with a
new date.

# Flowie 隐私政策

更新日期：2026-11-17

Flowie 不收集、不在任何服务器上存储、不分享也不出售任何个人信息。

- **笔记只保存在你的 Mac 上。** 你写的一切都保存在 Flowie 应用容器内的数据库中。Flowie 没有账号、云同步、统计分析、广告或崩溃上报，自身不发起任何网络请求。
- **你选择的文件。** 导入或导出时，Flowie 只读取或写入你在打开 / 保存对话框中选择的文件。
- **链接。** 点击网页链接会在默认浏览器中打开，之后的行为受该网站的政策约束。
- **AI 助手（可选）。** 如果你通过 Flowie 的 MCP 服务器连接 AI 助手（例如 Claude），该助手可以读取你的大纲；在「设置 → Agent」中允许后还可以修改。这种访问只通过你 Mac 上的本地连接进行。助手如何处理所读取的内容，受其提供方的政策约束。你可以随时关闭助手访问。
- **儿童。** Flowie 不从任何人（包括儿童）收集数据。

本政策如有变更，新版本会发布在本页面并更新日期。
