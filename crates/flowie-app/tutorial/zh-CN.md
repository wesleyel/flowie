- Flowie 教程——从这里开始 {{#tutorial}} {{star}}
  Flowie 的全部功能，每个标题一课。每试过一项就勾上它的方框。把鼠标移到某一课上、点击左侧的箭头，或按 ⌘↓ 展开。学完后删掉这一页即可——「帮助 → Flowie 教程」可以随时找回。
  - ## 1 · 书写
    - [ ] 点击这一行的末尾，按 Enter 新建条目
    - [ ] 按 Tab 缩进条目，Shift-Tab 取消缩进
    - [ ] 在条目开头按 Backspace，把它合并到上一条
    - [ ] 按 Shift-Enter 在条目下写备注
      就像这条。备注用来写较长的内容；再按 Shift-Enter 回到条目。
    - [ ] 按 ⌘Enter 完成条目，⌘O 显示或隐藏已完成的条目
      - ~~这条已经完成了~~
    - [ ] 用 ⌘⇧↑ / ⌘⇧↓ 移动条目，或拖动它的圆点
    - [ ] 按 Esc 选中整条，再用 Shift-↑ / Shift-↓ 扩大选择
      选中的多个条目可以一起缩进、移动、复制、剪切、完成或删除。也可以用鼠标拖过多行来选中。
    - [ ] 任何操作都能用 ⌘Z 撤销，⌘⇧Z 重做
    - 所有内容自动保存，只保存在你的 Mac 上
  - ## 2 · 页面与缩放 {{#zoom}} {{collapsed}}
    - [ ] 每个条目都是一个页面：点击条目的圆点（或按 ⌘]）进入它
    - [ ] 按 ⌘[ 返回上一层，⌘⇧H 回到主页；顶部的面包屑也能返回
    - [ ] 用鼠标的后退 / 前进键或 ⌘⌥← / ⌘⌥→ 在访问过的页面间切换
    - [ ] 按 ⌘↑ / ⌘↓ 折叠和展开条目
    - [ ] 按 ⌃1 – ⌃4 只显示 1–4 层，⌃0 全部展开
    - 一个折叠的条目——展开我 {{collapsed}}
      - 展开之前，这里是隐藏的
        - 条目可以无限嵌套
  - ## 3 · 块类型 {{collapsed}}
    - 在条目开头输入 / 打开命令菜单，或按 ⌘⌥0–8
    - # 一级标题
    - ## 二级标题
    - ### 三级标题
    - 不带圆点的正文 {{text}}
    - [ ] 待办——点击方框或按 ⌘Enter
    - [x] 已完成的待办
    1. 编号列表
    2. 会自动编号
    - > 引用
    - fn main() { println!("代码块"); } {{code}}
  - ## 4 · 文字样式 {{collapsed}}
    - **加粗** ⌘B · *斜体* ⌘I · ~~删除线~~ · `代码` ⌘E · ==高亮== ⌘⇧Y
    - 颜色：{red}红{/} {orange}橙{/} {yellow}黄{/} {green}绿{/} {blue}蓝{/} {purple}紫{/} {gray}灰{/}
    - [ ] 选中一段文字，右键打开样式菜单
    - [ ] 点击这一行：只有正在编辑的条目才会显示标记符号
    - 链接：用 ⌘K 插入 [标签](https://zh.wikipedia.org/wiki/大纲)，或直接粘贴网址，如 https://example.com
    - 像 {{today}} 这样的日期可以点击，会找出所有带这个日期的条目
  - ## 5 · 数学公式 {{collapsed}}
    - 行内公式用 `$…$` 或 ⌘M：$e^{i\pi}+1=0$
    - 独立公式用 `$$…$$`
      - $$\int_0^1 x^2\,dx=\frac{1}{3}$$
    - [ ] 点击公式即可编辑，行下方会实时预览
    - 像 $5 and $6 这样的价格保持为普通文字
  - ## 6 · 连接想法 {{collapsed}}
    - 标签 #想法 和提及 @小明：输入 # 或 @ 会自动补全，点击即可搜索
    - [ ] 输入 `[[` 或按 ⌘⇧K 链接到任意条目，例如 [页面与缩放](flowie:@zoom)
      打开那一课：页面底部会以反向链接的形式显示这条链接。
    - 镜像（⌘⌥M）让同一个条目出现在多个地方
      - 我是原件——编辑我，下面的副本会同步变化 {{#mirror}}
      - {{mirror mirror}}
    - [ ] 按 ⌘⇧M 把条目移动到其他页面，或移到主页下的新页面
    - [ ] 按 ⌘⇧S 收藏页面；这份教程已经收藏
  - ## 7 · 查找 {{collapsed}}
    - [ ] 按 ⌘P 跳转到收藏的页面、保存的搜索或任意条目
      输入一个还不存在的名字，即可在主页下新建页面。
    - [ ] 按 ⌘F 搜索，⌘G / ⌘⇧G 跳到下一个 / 上一个结果
    - 搜索条件："精确短语"、-排除、#标签、@人名、is:todo、is:open、is:done、is:heading、has:note、changed:7d、date:today、before:2026-12-01、after:today
    - [ ] 在搜索栏顶部保存搜索；"is:todo is:open" 已经保存好了——在 ⌘P 里找找看
  - ## 8 · 日记与日历 {{collapsed}}
    - [ ] 按 ⌘⇧D 打开今天的日记页
    - [ ] 按 ⌘⇧C 打开日历：点击某天打开那天的日记，⌥-点击查看带那天日期的条目
  - ## 9 · 导入、导出与废纸篓 {{collapsed}}
    - [ ] 按 ⌘⇧I 导入 OPML、Markdown 或纯文本——支持 Workflowy 导出的文件
    - 在「文件」菜单把当前页面或选中的条目导出为 Markdown（⌘⇧E）、OPML 或纯文本
    - 删除的条目（⌘⇧Backspace）会在废纸篓保留 30 天：「文件 → 废纸篓」
  - ## 10 · 个性化 {{collapsed}}
    - [ ] 按 ⌘, 打开设置：主题、强调色、语言
    - [ ] 在设置里点击任意快捷键即可修改；+ 可以再绑定一个按键或鼠标侧键
    - AI 助手可以通过 Flowie 的 MCP 服务器读取你的大纲，允许后还能编辑：「设置 → Agent」
      在 Claude Code 中，在终端运行：
      - claude mcp add flowie -- /Applications/Flowie.app/Contents/MacOS/Flowie mcp {{code}}
    - 有想法或遇到问题？「帮助 → 发送反馈…」
    - [ ] 学完了？用 Esc 选中这一页的条目，按 ⌘⇧Backspace 删除
