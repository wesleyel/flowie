- Flowie 教程——从这里开始 {{#tutorial}} {{star}}
  三部分：「入门」五分钟上手；「示例」是三种常见用法，可以直接改成你自己的；「手册」列出全部功能，用到时再查。带箭头的条目是折叠的：点击箭头，或把光标放在条目上按 {{key:expand}} 展开。学完后删掉这一页即可——「帮助 → Flowie 教程」可以随时找回。
  - # 入门
    - [ ] 点击这一行的末尾，按 Enter 新建条目；Tab 缩进，Shift-Tab 取消缩进
    - [ ] 按 Shift-Enter 在条目下写备注
      就像这条。备注用来写较长的内容；再按 Shift-Enter 回到条目。
    - [ ] 按 {{key:complete}} 勾掉一项待办，比如这一条
    - [ ] 点击条目的圆点进入它：每个条目都是一个页面。按 {{key:zoom-out}} 或点击顶部路径返回
    - [ ] 按 {{key:collapse}} / {{key:expand}} 折叠和展开条目——下面的「示例」就收起了三个页面
    - [ ] 按 {{key:jump}} 跳到任意页面，按 {{key:find}} 搜索
    - 所有内容自动保存在这台电脑上；任何操作都能用 {{key:undo}} 撤销

  - # 手册
    全部功能，一课一个标题。每试过一项就勾上它的方框。
    - ## 书写 {{collapsed}}
      - [ ] 在条目开头按 Backspace，把它合并到上一条
      - [ ] 按 {{key:toggle-completed}} 显示或隐藏已完成的条目
        - ~~这条已经完成了~~
      - [ ] 用 {{key:move-up}} / {{key:move-down}} 移动条目，或拖动它的圆点
      - [ ] 按 Esc 选中整条，再用 Shift-↑ / Shift-↓ 扩大选择
        选中的多个条目可以一起缩进、移动、复制、剪切、完成或删除。也可以用鼠标拖过多行来选中。
      - [ ] 按 {{key:redo}} 重做被撤销的操作
    - ## 页面与缩放 {{#zoom}} {{collapsed}}
      - [ ] 按 {{key:zoom-in}} 进入光标所在的条目，{{key:home-page}} 回到主页
      - [ ] 用鼠标的后退 / 前进键或 {{key:page-back}} / {{key:page-forward}} 在访问过的页面间切换
      - [ ] 按 {{key:level-1}} – {{key:level-4}} 只显示 1–4 层，{{key:expand-all}} 全部展开
      - 向下滚动时，页面标题会收进顶栏，路径显示你正在看的位置
      - [ ] 按 {{key:scroll-bottom}} 跳到长页面的末尾，按 {{key:scroll-top}} 回到顶部
      - 一个折叠的条目——展开我 {{collapsed}}
        - 展开之前，这里是隐藏的
          - 条目可以无限嵌套
    - ## 块类型 {{collapsed}}
      - 在条目开头输入 /（中文输入法下输入 、 也可以）打开命令菜单，或按 {{key:kind-bullet}}–{{key:kind-code}}
      - # 一级标题
      - ## 二级标题
      - ### 三级标题
      - 不带圆点的正文 {{text}}
      - [ ] 待办——点击方框或按 {{key:complete}}
      1. 编号列表
      2. 会自动编号
      - > 引用
      - fn main() { println!("代码块"); } {{code}}
    - ## 文字样式 {{collapsed}}
      - **加粗** {{key:bold}} · *斜体* {{key:italic}} · ~~删除线~~ · `代码` {{key:code}} · ==高亮== {{key:highlight}}
      - 颜色：{red}红{/} {orange}橙{/} {yellow}黄{/} {green}绿{/} {blue}蓝{/} {purple}紫{/} {gray}灰{/}
      - [ ] 选中一段文字，右键打开样式菜单
      - [ ] 点击这一行：只有正在编辑的条目才会显示标记符号
      - 链接：用 {{key:link}} 插入 [标签](https://zh.wikipedia.org/wiki/大纲)，或直接粘贴网址，如 https://example.com
      - 像 {{today}} 这样的日期可以点击，会找出所有带这个日期的条目
    - ## 数学公式 {{collapsed}}
      - 行内公式用 `$…$` 或 {{key:math}}：$e^{i\pi}+1=0$
      - 独立公式用 `$$…$$`
        - $$\int_0^1 x^2\,dx=\frac{1}{3}$$
      - [ ] 点击公式即可编辑，行下方会实时预览
      - 像 $5 and $6 这样的价格保持为普通文字
    - ## 图片 {{collapsed}}
      - 粘贴图片、把图片拖到条目上，或按 {{key:insert-image}} 插入；条目文字就是图片说明
      - Flowie 的图标 {{image icon}}
      - [ ] 选中上面的图片条目，按空格查看大图
    - ## 连接想法 {{collapsed}}
      - 标签 #想法 和提及 @小明：输入 # 或 @ 会自动补全，点击即可搜索
      - [ ] 输入 `[[` 或按 {{key:link-to}} 链接到任意条目，例如 [页面与缩放](flowie:@zoom)
        打开那一课：页面底部会以反向链接的形式显示这条链接。
      - 镜像（{{key:mirror}}）让同一个条目出现在多个地方
        - 我是原件——编辑我，下面的副本会同步变化 {{#mirror}}
        - {{mirror mirror}}
      - [ ] 按 {{key:move-to}} 把条目移动到其他页面，或移到主页下的新页面
      - [ ] 按 {{key:star}} 收藏页面；这份教程已经收藏
    - ## 查找 {{collapsed}}
      - [ ] 在 {{key:jump}} 里输入一个还不存在的名字，即可在主页下新建页面
      - [ ] 搜索时按 {{key:next-match}} / {{key:prev-match}} 跳到下一个 / 上一个结果
      - 搜索条件："精确短语"、-排除、#标签、@人名、is:todo、is:open、is:done、is:heading、has:note、changed:7d、date:today、before:2026-12-01、after:today
      - [ ] 在搜索栏顶部保存搜索，保存的搜索会出现在 {{key:jump}} 里
    - ## 日记与日历 {{collapsed}}
      - [ ] 按 {{key:today}} 打开今天的日记页
      - [ ] 按 {{key:calendar}} 打开日历：点击某天打开那天的日记，{{mod:alt}}-点击查看带那天日期的条目
    - ## 导入、导出、分享与废纸篓 {{collapsed}}
      - [ ] 按 {{key:import}} 导入 OPML、Markdown 或纯文本——支持 Workflowy 导出的文件
      - 在「文件」菜单把当前页面或选中的条目导出为 Markdown（{{key:export-md}}）、OPML 或纯文本
      - 要把条目发给另一位 Flowie 用户，在条目菜单里选「导出为分享包…」（或输入 /export）：得到一个包含这些条目及其所有子条目的 `.flowie` 文件
      - 打开别人发来的 `.flowie` 文件即可导入；新导入的条目会显示一个圆点，打开后消失（搜索 `is:new` 可找到它们）
      - 删除的条目（{{key:delete-bullet}}）会在废纸篓保留 30 天：「文件 → 废纸篓」
    - ## 个性化与 AI {{collapsed}}
      - [ ] 按 {{key:settings}} 打开设置：主题、强调色、内容宽度、语言
      - [ ] 窗口很宽时，按 {{key:content-width}} 在窄、适中、全宽三档之间切换文字栏的宽度
      - [ ] 在设置里点击任意快捷键即可修改；+ 可以再绑定一个按键或鼠标侧键，搜索框可以按名称或按键查找
      - AI 助手可以通过 Flowie 的 MCP 服务器读取你的大纲，允许后还能编辑：「设置 → Agent」
        在 Claude Code 中，在终端运行：
        - {{mcp-command}} {{code}}
      - 在 Windows 和 Linux 上，关闭窗口时可以让 Flowie 留在系统托盘里继续运行，AI 助手仍能访问，点托盘图标即可重新打开窗口：「设置 → 通用」
      - 想让几台设备上的大纲保持一致：在「设置 → 同步」里选择 iCloud（App Store 版），或者运行一台自己的 Flowie 服务器
      - 「帮助 → 新功能」列出每个版本的变化；有想法或遇到问题？「帮助 → 发送反馈…」
