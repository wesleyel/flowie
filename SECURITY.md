# Security

Flowie stores your outline in a local SQLite database and makes no network requests of its
own. The optional MCP server (Settings → Agent) talks to the AI client that launches it over
standard input and output only.

## Reporting a vulnerability

Please report it privately through
[GitHub security advisories](https://github.com/wesleyel/flowie/security/advisories/new),
or by e-mail to wesleyel@icloud.com. Don't open a public issue.

You'll get an answer within a week. Fixes ship in the next App Store release; only the latest
version is supported.
